# Published de-core-45 scores

`tasks/<task>/scores.json` contains the final historical August 4 evaluation:
Luna and Terra are the primary judges; Gemini resolves disagreements. The files
were reconstructed from the original and recheck vote caches on August 21,
2026. `scored_at` is the reconstruction timestamp, not a new judging run.

See [the study score documentation](../../../studies/de-core-45/scores.md)
for provenance, field names, reproduction, and the missing-submission case.
The old July 31 failed scores remain available in Git history, before this
publication update. They must not be used for error analysis.
