If the gold solution discusses an expressly excluded issue, ignore that discussion for scoring. Preserve a correct scope-compliance criterion or drop an unsupported content criterion; never rewrite it to require the excluded examination.

From the judge feedback, decide why the gold solution did not clearly pass: the requirement is absent from the solution, the criterion bundles several requirements, the criterion lacks facts or context the judge needs, the wording is ambiguous, or the wording is over-specific to one formulation.

If the gold solution satisfies the point in a file the criterion does not list AND the task permits that location, add exactly that file to "deliverables". If the task does not permit that location, the criterion tests the wrong location claim; fix or drop the criterion, never the location rule.
- Never widen or narrow a criterion's "deliverables" list beyond the locations the task itself permits.

If the gold solution itself contains only the heading or bare conclusion, drop the criterion rather than weakening it into a mention check.

- If the criterion requires incidental numerical or verbal precision that is not legally material according to the task or solution, rewrite it around the legally relevant relationship; if no material proposition remains, drop it.
