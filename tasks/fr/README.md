# Tâches françaises

Les tâches françaises utilisent le même contrat de fichiers que les tâches
allemandes :

```text
tasks/fr/<domaine>/<type>/<tâche>/
  task.json
  documents/
  evals/
    loesung.md
    rubric.json
```

Le premier cas CRFPA est un pilote technique. Sa solution de référence et sa
grille reconstruite doivent encore être validées par des juristes français et,
si possible, rapprochées de la grille officielle CNB/IEJ. Le fait que la tâche
soit exécutable par le harnais ne constitue pas une validation juridique.
